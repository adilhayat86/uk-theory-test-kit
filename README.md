# UK Theory Test Kit

An independent, offline-first UK car theory test preparation app for Android and iOS.

## Product decisions
- UK market
- React Native + Expo, TypeScript
- £0.99 one-time purchase target; no ads or subscription
- Offline access to question bank, explanations, road signs, mock tests, hazard-perception practice, bookmarks and progress
- Original educational content; not affiliated with or endorsed by DVSA

## Development status
Project scaffold initialisation. The app and test suites will be added incrementally.

## Local development
Install Node.js LTS and dependencies, then run:

```bash
npm install
npx expo start
```

## Content and compliance
All questions, explanations, illustrations and hazard-perception scenarios must be original or appropriately licensed. Verify current exam requirements against official GOV.UK/DVSA guidance before release.
